# SalesWorlds

SalesWorlds is a fully synthetic B2B sales dataset for testing AI systems built for sales work. It holds one fictional
company's sales record as of a test date (a CRM with field history, recorded call transcripts, email, chat, documents
and calendars) and benchmark questions about it, each with an answer key and the evidence behind it.

**The dataset is on Hugging Face: [EndgameLabs/SalesWorlds](https://huggingface.co/datasets/EndgameLabs/SalesWorlds).**
Its dataset card explains what is in it, how to load it and how answers are graded.

## Reporting a problem

Open an issue in this repository. Include the dataset revision you used, the question id or record id, what you
expected and what the data shows. Corrections ship as a new release; a published release is never edited in place.
